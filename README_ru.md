# Discord Canary Updater для Arch Linux

Простой инструмент автоматизации для поддержания актуальности Discord Canary в системах Arch Linux.

[English](README.md) | [中文](README_zh.md)

## Проблема

Пользователи Arch Linux, использующие официальную версию Discord Canary (tar.gz), сталкиваются с неприятной особенностью: при каждом запуске приложение может требовать скачать обновление. Вручную скачивать архив, распаковывать его и заменять файлы каждый день — утомительно и неудобно.

## Решение

Этот простой скрипт на Go решает проблему автоматизации. Он выполняет следующие действия:

- Скачивает актуальный архив discord-canary.tar.gz с официального сервера Discord.
- Распаковывает его.
- Заменяет старую версию на новую.

## Установка

1. Скачайте последнюю версию со страницы [Релизы](https://github.com/Lazlo105/Discord-canary-updater-for-Arch-linux/releases/latest).
2. Выдайте права на исполнение:
   ```bash
   chmod +x discord-updater
   ```
3. Запустите обновитель:
   ```bash
   ./discord-updater
   ```

## Требования

- Go версии 1.20 или выше (для сборки из исходного кода)
- Make (опционально, для использования целей Makefile)

## Сборка из исходного кода

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Lazlo105/Discord-canary-updater-for-Arch-linux.git
   cd Discord-canary-updater-for-Arch-linux
   ```

2. Соберите проект:
   ```bash
   make build
   ```

3. Запустите приложение:
   ```bash
   ./bin/updater
   ```

## Разработка

- Форматирование кода: `make fmt`
- Запуск тестов: `make test`
- Запуск линтера: `make lint`
- Просмотр покрытия: `make test-coverage`
